# Jay Deaton

Developer and maker with a weakness for cross-platform. I reach for React Native and Electron because I'd rather build something once and have it run everywhere — then fill the gaps with Node.js APIs, Vue.js web tools, Swift packages, and whatever the Arduino or 3D printer demands next.

Co-owner at [Infinite Token](https://github.com/infinitetoken), where most of my professional work lives. The rest — open source components, CLI tools, and side projects — lives here.

Available for freelance work out of Lincoln, NE.

---

## What I build

- **React Native / Expo** — cross-platform mobile apps and UI components
- **Electron** — cross-platform desktop apps
- **Node.js / TypeScript** — APIs, CLI frameworks, developer tools
- **Swift** — iOS apps and packages via [Infinite Token](https://github.com/infinitetoken)
- **Web** — Vue.js interfaces, web utilities, browser tools
- **Hardware** — Arduino projects, Fusion 360 macros, 3D printing
